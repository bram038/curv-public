# curv-public

This repository contains public documentation and supporting files for the **Curv** app.

Curv is a motorcycle route planning app that generates circular routes based on a starting location and your preferred distance and road style. It is available on the Google Play Store.

## What you'll find here

| File | Description |
|---|---|
| [Privacy Policy](docs/privacy-policy.md) | The privacy policy for the Curv app, as required by the Google Play Store |

## Why this repository exists

The main Curv codebase is kept in a private repository. This public repository exists to host documents that need to be publicly accessible — such as the privacy policy — without exposing the application source code.
