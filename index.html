Curv Public Documentation

This repository contains public documentation and supporting files for the Curv app. Curv is a motorcycle route planning app that generates circular routes based on a starting location and your preferred distance and road style.

Documents

  • Privacy Policy The privacy policy for the Curv app.
  • Terms of Use The terms that apply when using Curv.

Why This Repository Exists

The main Curv codebase is kept in a private repository. This public repository exists to host documents that need to be publicly accessible, such as privacy and legal documentation, without exposing the application source code.
